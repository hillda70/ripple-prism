# The Mechanistic Metaphor

Modern finance inherited a root metaphor so deeply embedded that it no longer appears as metaphor at all.

Markets became understood as machines:

* equilibrating systems
* rational distributions
* information processors
* volatility engines
* optimization structures

The metaphor was enormously productive.

It produced:

* derivatives pricing
* risk decomposition
* hedging systems
* portfolio theory
* quantitative finance itself

But over time the mechanistic metaphor became totalizing.

Signals began to appear as possessing fixed meanings:

* RSI above 70 is overbought
* Bollinger squeezes imply breakout
* volatility expansion implies danger
* momentum implies continuation

The machine became assumed.

Yet markets repeatedly behave like adaptive organisms instead:

* transmitting
* absorbing
* saturating
* stabilizing
* reorganizing

The same signal behaves differently in different propagation ecologies.

Meaning emerges contextually.

This is the contextualist inversion:
the regime is assumed first.
The signals derive meaning from it.

The market is not merely price.
It is an adaptive propagation system.

## Root Metaphors

Stephen C. Pepper argued that world hypotheses emerge from root metaphors.

Mechanism:
the world as machine.

Organicism:
the world as living whole.

Strawberry Canyon increasingly operates through an organismic and contextualist metaphor:

* markets as adaptive physiological systems
* volatility as regulatory behavior
* propagation as force transmission
* gamma as curvature
* participation as ecological sponsorship

The whole is assumed first.
The parts derive meaning from it.
